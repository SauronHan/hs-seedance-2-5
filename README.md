# hs-seedance-2-5

> [English](README_EN.md) | **中文**

火山引擎 Doubao Seedance 2.5 电影级提示词生成与底模原生编译器（Skill）。

专为生成顶级电影质感视频打造，严格落实**黄金四段式结构**（素材指代映射 + 宏观风格综述 + 时间轴微观推进 + 全局视听与负向死锁），两阶段特征描述解耦（防僵尸脸），支持独立高清单图角色锁定、双色轨迹引导、3D白模视频骨架驱动及音视频一体化排他性防串音控制。

---

## 🌟 核心特性

- **纯原生底模注意力编排**：基于 Seedance 2.5 Transformer 架构的时间与空间注意力规律设计，彻底消除“提示词悬空”与“属性漂移”。
- **两阶段特征解耦（防僵尸脸）**：素材段显式排除棚拍无阴影平光与呆板中性站姿，将所有光影、微表情变化与戏剧调度全额留给时间轴动态赋予。
- **三级运动控制体系（互斥与降级）**：
  - **Level 1（纯文本时间轴）**：适用于常规对话、平缓推进与自然微距。
  - **Level 2（双色视觉轨迹图）**：利用手绘红蓝线条精准约束主体走位与穿梭运镜，并强制注入「消线死锁」。
  - **Level 3（3D 灰模/动捕视频驱动）**：针对复杂高低差对峙、特技打斗与精密空间几何位移，以 3D 几何视频为物理骨架驱动。
- **音视频一体化排他性防串音**：支持环境纯拟音（Foley）、画外音与声画对白口型同步（Lip-sync），通过高频物理打桩严禁串音与机器杂音。
- **轻量独立**：纯自然语言编译引擎，零外部重型依赖，可在任意支持 AI Agent 的环境中即插即用。

直接在 AI 聊天对话中发送您的创意构思、分镜剧本或素材描述：
